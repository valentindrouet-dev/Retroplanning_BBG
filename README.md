# Rétroplanning BBG

Rétroplanning des jeux Big Budi Games (TornaDice, EDIT, Camino), jusqu'à l'envoi en fabrication.

Page autonome : `index.html`. Les données sont intégrées dans la page (bloc `<script id="state">`).

## Mise en ligne (GitHub Pages)

Settings → Pages → Source : *Deploy from a branch* → choisir la branche et le dossier `/ (root)`.

## Modifications

Hors de Claude.ai, les modifications faites dans la page sont enregistrées **uniquement dans le navigateur** (localStorage).
Pour les partager avec toute l'équipe, il faut mettre à jour `index.html` dans le dépôt.

## Sauvegarde

- **Sauvegarde JSON** (en haut à droite) télécharge toutes les données dans un fichier.
- **Importer JSON** recharge une sauvegarde et remplace les données de la page.
- **PDF complet** exporte les 3 jeux et l'onglet Communication dans un seul PDF.
